# Visible demonstrations and reusable skills

`soma/demonstration.py` records only monitor PNGs and native mouse/keyboard events during an explicit demonstration. Importing the module creates no global hooks. `start()` inhibits the human-interface port before constructing or starting listeners. Windows uses pynput's Win32 backend; Linux requires X11 and the xorg backend. Native Wayland is rejected. No window titles, process names, DOM, accessibility fields, clipboard contents, or application files enter the trace.

`LifeKernel._controls()` captures an initial fresh screen immediately after start and a final screen before an ordinary finish. It skips final capture for private mode, suspend, or shutdown. A capture failure still stops and joins the listeners. The completed trace and pending-lesson checkpoint become durable before input resumes. A recorder failure leaves motor output inhibited. The recorder itself never resumes autonomy; the life kernel owns that transition.

Each trace contains an ID, timestamps, frame records, raw input steps, explicit gaps, and truncation status. A step references `before_frame_id`, `after_frame_id`, and its native input event. The screen adapter records a monotonic timestamp immediately before grabbing pixels; a frame begun before an event cannot serve as that event's after evidence. Events without preceding pixels are omitted and counted; trailing inputs without later pixels remain explicitly incomplete. Signed global coordinates preserve displays left of the primary screen. Consecutive pointer moves are coalesced; the trace is evidence, never an executable macro.

The visible sensitive toggle pauses both pixel and input retention while the inhabitant's own input remains inhibited. It resets visual context, marks a gap, and prevents associations across that gap. A slow screenshot whose acquisition overlaps a private interval is discarded even if it arrives after recording resumes. Queued input with a timestamp inside a private interval is discarded. Inclusive boundaries conservatively omit events sharing a coarse clock tick with the gap. Use the toggle before entering sensitive information and resume after that information is no longer visible. Win32 surrogate code units are retained as explicit `U+XXXX` tokens rather than invalid Unicode or guessed characters.

Recording stops retaining evidence at 10,000 accepted native input deltas, 600 frames, 128 MiB of PNGs, or 128 private segments. Pointer motion is sampled at up to 20 Hz; accepted coalesced updates count toward the input limit. Click, button, and key boundaries are retained. Capacity truncation continues to inhibit autonomous input until the demonstration is explicitly finished. These bounds are per demonstration; the memory store separately bounds retained frame storage.

Every accepted input is committed to the append-only event journal before its callback returns. A coalesced move updates the same step index through a new small event; a frame delta contains one frame and its paired input indices. Privacy/capacity changes journal gap metadata without sensitive values. No callback or frame writes the entire growing trace. After a crash, `reconstruct_interrupted_demonstrations()` rebuilds only known observations, preserves valid before/input/after triples, and marks unknown trailing outcomes as interrupted. It never restarts hooks or replays input. Completed, acquired, unusable, and failed-start traces are excluded from interrupted reconstruction. Startup merges interrupted observations with completed raw episodes awaiting semantic learning.

The X11 listener adapter terminates X RECORD through its separate control connection and flushes that request. This fixes pynput 1.x's stop request otherwise waiting on its blocked recording connection; shutdown requires no synthetic input to wake it.

`LifeKernel._learn()` reads only recorded image paths within the inhabitant's own frame directory. It attaches at most eight evenly spaced retained frames, with explicit image-index/frame-ID mapping. Movement summaries preserve gaps. The inference trace is capped at 128 summarized steps and 24,000 JSON characters and reports omitted evidence. Missing/private pixels are unknown, never inferred as recorded facts.

The model proposes a semantic skill: purpose, visual preconditions, principles, visible targets, expected visual results, and recovery guidance. Only those fields become procedural memory. Additional executable actions or coordinate payloads are discarded; every later action still passes through ordinary fresh-screen grounding and the single validated motor port. A demonstration with no retained image/input evidence receives an explicit unusable record. Original observations remain episodic memory with provenance. Pending completed demonstrations survive restart; acquired or unusable demonstrations are excluded from the pending queue.

Verification:

```powershell
.venv/Scripts/python.exe -m pytest tests/test_demonstration.py tests/test_demonstration_recovery.py tests/test_learning_integration.py -q
```

These tests use fake listeners and an actual SQLite memory store to verify synchronization, lifecycle races, privacy omissions, bounded evidence, restart continuity, and absence of macro execution. The separate owned Qt desktop fixture exercises native input and pixels; its injected-input-only teaching evidence is under `docs/evidence/windows-desktop/`. No real model generalization or real human teaching-transfer result is established by these tests. Those acceptance gates remain unrun until demonstrated against a configured model and controlled desktop workflow variants.
